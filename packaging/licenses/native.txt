Libraries loaded at run time, and the bundled font
------------------------------------------------------------------------------------------------------------------

libmpv (mpv) — GNU Lesser General Public License, version 2.1 or later (LGPL-2.1+)
  Video and audio playback. RustyPresenter loads libmpv-2.dll (libmpv.so / libmpv.dylib) at run time and does not
  change it; you may replace it with your own build of the same interface. Source code:
  https://github.com/mpv-player/mpv
  The exact sources of the build shipped with a release, and its build scripts, are offered with that release at
  https://github.com/SuperDuperSoft/RustyPresenter/releases

FFmpeg libraries (libavcodec, libavformat, libavutil, libswscale, libswresample, libavfilter) — GNU Lesser General
Public License, version 2.1 (LGPLv2.1), as built into the shipped libmpv (no GPL or non-free parts enabled).
  Source code: https://ffmpeg.org/download.html, and with each release at
  https://github.com/SuperDuperSoft/RustyPresenter/releases

pdfium — BSD-3-Clause and Apache-2.0 (with third-party parts under their own permissive licences)
  PDF rendering for slide import, loaded at run time by releases that include it.
  Source code: https://pdfium.googlesource.com/pdfium/

Noto Sans — SIL Open Font License, version 1.1 (OFL-1.1)
  The bundled fallback font for slides. Copyright 2022 The Noto Project Authors
  (https://github.com/notofonts/latin-greek-cyrillic). The font may be used, studied, modified and redistributed
  freely as long as it is not sold by itself; see https://openfontlicense.org.

The full texts of the GNU LGPL 2.1 and the SIL OFL 1.1 are at https://www.gnu.org/licenses/old-licenses/lgpl-2.1.txt
and https://openfontlicense.org/open-font-license-official-text/.

------------------------------------------------------------------------------------------------------------------
Programs downloaded on first use (Download from YouTube) — not part of the installer
------------------------------------------------------------------------------------------------------------------

The first time Download from YouTube is used, RustyPresenter downloads these programs from their official release
pages into its data folder (deps\yt-dlp, deps\deno, depsfmpeg), checks each against the SHA-256 fingerprint
published beside it, and runs them as separate programs. RustyPresenter does not change or redistribute them.

yt-dlp — The Unlicense (public domain). The official builds bundle Python and other libraries, so each build as a
whole is under the GNU General Public License, version 3 or later (GPL-3.0+).
  Reads YouTube and saves the video. Checked for a newer release at most once a day while the feature is used.
  Source code: https://github.com/yt-dlp/yt-dlp

Deno — MIT License. Copyright the Deno authors.
  Runs YouTube's JavaScript checks for yt-dlp, with no access to files or the network.
  Source code: https://github.com/denoland/deno

FFmpeg (ffmpeg, ffprobe) — GNU General Public License, version 3 or later (GPL-3.0+), as built with x264 and other
GPL parts. Joins YouTube's separate picture and sound into one MP4; also used to convert unusual videos.
  Windows builds: https://github.com/yt-dlp/FFmpeg-Builds (build scripts and sources of every part).
  macOS and Linux builds: https://ffmpeg.martin-riedl.de (build scripts at https://git.martin-riedl.de/ffmpeg/build-script).
  FFmpeg source code: https://ffmpeg.org/download.html

The full text of the GNU GPL 3 is at https://www.gnu.org/licenses/gpl-3.0.txt, and of the MIT License at
https://opensource.org/license/mit.
