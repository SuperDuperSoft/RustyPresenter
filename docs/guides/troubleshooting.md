# When something goes wrong

## During the service

**The audience screen shows the wrong thing.** Press `F1` to clear it, then click the slide you want.

**I cannot find the mouse.** It is probably on the projector. **Help → Find my mouse** brings it back.

**The words changed but the screen did not.** Click **Update screen**, or click the slide again.

## Screens

**The audience screen is black or missing.** Check the cable. Press `Win + P` and choose **Extend**. Then **Window → Screens…** and click **Refresh**.

**The screens flicker, stay black, or RustyPresenter closes as it starts.** This is usually the graphics card. Open **Settings → Video…**, choose another kind of graphics, and restart. **Software (safe mode)** always works; video is smoother with the others.

If RustyPresenter fails to start twice in a row, it starts the next time in safe mode by itself and says so.

## Phones

**The phone cannot connect.**

1. Is the phone on the same Wi-Fi as the computer? Guest Wi-Fi often keeps devices apart.
2. Did Windows ask about the network, and did you click **Allow**? If not: open **Windows Security → Firewall & network protection → Allow an app through firewall**, find RustyPresenter, and tick **Private**.
3. Pair again: **Window → Remote…**, then **Pair a phone or tablet**. A QR code expires after a while.

## Bible

**"Couldn't reach…" when looking up a passage.** That Bible is read over the internet and the computer is offline. Use KJV, WEB or BSB, which need no internet, or add an **Offline** Bible in **Settings → Bible…**

**A Bible I want is not listed.** See [Bible](bible.md) for what is and is not available.

## Videos and slides

**A PowerPoint will not import.** Install LibreOffice (free), or save the file as PDF and add that.

**A video has no sound in the room.** Check the sound output in **Settings → Media and sound…**

## Installing

**Windows says "Windows protected your PC".** Click **More info**, then **Run anyway**. The installer is not signed yet.

**Windows blocks it with no "Run anyway" button.** Smart App Control is on. It has to be turned off in Windows Security before unsigned apps can run.

## Still stuck

1. **Help → Report a problem…** writes a note to fill in.
2. **Help → Open logs folder** shows the log files.
3. Send both to whoever looks after RustyPresenter at your church, or [open an issue](https://github.com/SuperDuperSoft/RustyPresenter/issues) and attach them.
