# Keys

These are the keys RustyPresenter starts with. **Settings → Keys and clear groups…** changes them. **Help → Keyboard shortcuts** shows the keys as your church has set them.

## Moving

| Key | Does |
| --- | --- |
| `→` `Space` `Page Down` | Next slide |
| `←` `Page Up` | Back |
| `Enter` | Show the selected item |

## Clearing the screen

| Key | Does |
| --- | --- |
| `F1` | Clear all |
| `F2` | Clear text (the background stays) |
| `F3` | Clear media & background (the words stay) |
| `F4` | Clear audio |
| `F5` | Logo |
| `F6` | Clear overlays |
| `F7` | Clear the message |
| `F8` | Clear the timers |

## Songs

| Key | Jumps to |
| --- | --- |
| `C` | Chorus |
| `B` | Bridge |
| `P` | Pre-chorus |
| `E` | Ending |
| `1` to `9` | That verse |

## Other

| Key | Does |
| --- | --- |
| `Ctrl + B` | Bible box |
| `Ctrl + V` | Add a YouTube link you copied |
