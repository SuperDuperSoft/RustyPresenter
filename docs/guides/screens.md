# Screens

RustyPresenter uses up to three kinds of screen:

| Screen | Who sees it | What it shows |
| --- | --- | --- |
| **This computer** | The person running the slides | The service, the slides and the controls |
| **Audience screen** | Everyone in the room | The slide |
| **Stage screen** | The band and the speaker | What they need to lead: the words, and messages from you |

## Set them up

1. Plug in the projector or TV.
2. Press `Win + P` and choose **Extend**.
3. Open **Window → Screens…**
4. Choose the monitor for the audience screen, and one for the stage screen if you have it.

**Identify** puts a label on each monitor. If a screen is missing from the list, check the cable and click **Refresh**.

## The stage screen

- **Window → Stage layouts…** chooses what the stage screen shows and where.
- **Window → Stage message…** sends a short message to the band or speaker ("2 minutes left"). Leave it empty to take it down. `F7` clears it too.
- A phone or tablet can show the stage screen as well. See [Phone remote](remote.md).

## Check what the room sees

**View → Preview the audience screen** shows a small copy of the audience screen on this computer, so you do not have to turn around.

## Lost the mouse?

If the pointer has wandered onto the projector, **Help → Find my mouse** brings it back.
