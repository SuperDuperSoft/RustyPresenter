# Videos, pictures and slides

## Add a file

Drag it onto the window, or use **File → Add to service**:

- **Video & media…** for videos, pictures and music.
- **Slides…** for PowerPoint, Keynote and PDF files.

Almost any video or audio file plays as it is. There is nothing to convert.

## PowerPoint, Keynote and PDF

- To import PowerPoint or Keynote files on a computer without PowerPoint, install **LibreOffice** (free, from libreoffice.org).
- **Google Slides:** in Google Slides choose **File → Download → Microsoft PowerPoint (.pptx)** or PDF, then add that file.
- To change the words inside RustyPresenter, use **File → Import → PowerPoint words as editable slides…** (only for .pptx files).

## The media library

The bottom of the window lists every video, picture and song file you have added, in folders.

- **Double-click** one to make it the background of the item you picked.
- **Add to service** puts it in the service as its own item.
- **File → Clean up unused media…** frees disk space.

## Backgrounds and the logo

- **Settings → Themes and backgrounds…** sets the usual background for songs and Bible passages.
- `F5` shows your church logo. Choose the logo in the Look page of Settings.
- `F3` takes the video or picture away and leaves the words.

## Music before the service

**Window → Walk-in music…** plays music while the slides change. `F4` (Clear audio) or `F1` (Clear all) stops it.

**Window → Start pre-service** puts the music and slides up and counts down to the start time.

## Announcements and overlays

- **File → Add to service → Announcement…** makes a simple text slide.
- **Settings → Overlays…** has things that sit on top of the slide, such as a sign with the Wi-Fi password.
- `F6` clears every overlay.
