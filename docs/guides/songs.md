# Songs

## Add a song

**File → Add to service → Song…** opens your song library. Pick a song, or make a new one and type or paste the words.

Leave an empty line between verses. Each part gets a label (Verse 1, Chorus, Bridge) and its own colour, so you can find it quickly on Sunday.

## Bring songs in

| From | How |
| --- | --- |
| **SongSelect** (CCLI) | **File → Add to service → Songs from SongSelect…** Songs you download from SongSelect in your web browser can also come into the library by themselves. |
| **EasyWorship 6 or 7** | In the song window, choose **Import from EasyWorship** and pick the library folder. Every song is copied once. EasyWorship itself is not changed. |
| **The clipboard** | Copy the words anywhere, then **File → Import → Song from the clipboard**. |
| **A file** | Drag a SongSelect, ChordPro or .usr file onto the window. |

## Find a song

**Edit → Quick search…** finds a song in the library.

## Edit a song

Double-click a song to change its words. If the song is on the screen while you edit it, **Update screen** shows the new words.

Right-click a slide to split it, join it with the next, or change which part it belongs to.

## During the song

While a song is on the screen:

| Key | Jumps to |
| --- | --- |
| `C` | Chorus |
| `B` | Bridge |
| `P` | Pre-chorus |
| `E` | Ending |
| `1` to `9` | That verse |

## How it looks

**Settings → Themes and backgrounds…** sets the font, the size and the background for songs. A single song can have its own background: pick the song, then double-click a picture or video in the media library.

## Reporting song use

**File → Song use report…** lists which songs were shown and when, for your CCLI report.
