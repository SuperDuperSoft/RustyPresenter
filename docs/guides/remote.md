# Phone remote

A phone or tablet can run the slides, so the person leading can move around, or a helper can sit anywhere in the room.

## What you need

- The phone and the computer on the **same Wi-Fi**.
- When Windows first asked whether RustyPresenter may use the network, you clicked **Allow** for private networks. If you did not, see [When something goes wrong](troubleshooting.md).

## Connect a phone

1. On the computer, open **Window → Remote…**
2. Click **Pair a phone or tablet**. A QR code appears.
3. On the phone, open the camera and point it at the code. Tap the link that appears.

The phone now shows the service and can move the slides.

If the camera will not scan, open the address shown with the code in the phone's web browser and type the 6-digit code.

## Android app

Any phone works in its web browser. For Android there is also an app, `RustyPresenter-Remote-<version>.apk`, on the [releases page](https://github.com/SuperDuperSoft/RustyPresenter/releases/latest). Android will ask you to allow installing it, because it is not from the Play Store.

## Keep strangers out

In **Settings → Remote and network…** you can switch on **Ask for a password when a phone or tablet pairs**. Phones already paired stay paired.

## More a phone can do

- **Show the stage screen**, for a singer who cannot see the stage monitor.
- **Be a camera or microphone** for the livestream.

Both are set up in **Settings → Remote and network…**
